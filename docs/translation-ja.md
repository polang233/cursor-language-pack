# 日语译文约定

日语支持覆盖官方 VS Code 基础资源、Cursor 自有 NLS、程序内界面文案、用量与付款界面及语言包提示。

优先使用常见的软件术语：設定、拡張機能、ワークスペース、リポジトリ、ブランチ、エージェント、プロンプト、コンテキスト。Cursor、Composer、Bugbot、MCP 和模型名称保留原名。

按钮和菜单使用简短的操作表达，例如「設定を開く」「変更を確定」「元に戻す」。标题采用名词短语；错误提示说明问题和必要的下一步。避免机械照搬英语语序，也不要为了补全语法在短标签中堆叠说明。

以界面含义为准区分 Run、Apply、Keep 和 Accept。菜单助记符、占位符、命令链接、ICU 分支和组件标签必须保持有效。长提示允许自然换行，不能为了缩短文案省略权限、费用、数据移动或操作不可撤销等关键信息。

维护时对照当前客户端检查新增、删除和变更文案，并校验日语实际构建、安装、重复安装、简繁体切换和恢复。菜单、按钮及过长译文需要单独检查。
